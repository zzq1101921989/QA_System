# “成长手账”治愈系学习系统设计方案

## 1. 核心理念
抛开传统“阅读-回答”的单向模式，将学习过程重构为**“经历-收集-创作”**的探索旅程。通过手账化的视觉呈现，让每一次微小的进步变得可见、可感、可收藏。

## 2. 目标受众与内容
- **年龄段**: 6–12 岁（小学阶段）
- **内容类型**: 文科类为主（语文、历史、道德与法治等）
- **学习颗粒度**: 以单元中的“小节”为单位（约 10–15 分钟闭环）

## 3. 核心玩法：四步仪式感
每一小节的学习被固定为一个标准仪式，确保孩子有掌控感且不疲劳：
1. **预测贴 (30s)**:
   - 木木发起：“今天这小节，你猜它想告诉你什么？”
   - 孩子输入预测，自动生成一张“预测贴纸”置于手账顶端。
2. **寻证背包 (3–6min)**:
   - 在左侧阅读区寻找支持或挑战预测的“证据”（句子、词语或图表）。
   - 放入右侧“证据背包”，每条证据需标注“它证明了什么”。
3. **创作作品 (2–4min)**:
   - 从三个模板中任选其一，将寻得的证据转化为作品。
4. **成长章 (30s)**:
   - 回答：“我原来以为... 现在我觉得...”。
   - 盖上“成长印章”，完成今日手账页。

## 4. 作品模板 (根据内容轮换)
- **模板 A：三格手账 (6–8岁)**: [我看到] + [我想到] + [我找到一句话证明]。
- **模板 B：人物档案 (文科核心)**: [人物是谁] → [做了什么] → [动机/证据] → [我的评价]。
- **模板 C：观点卡 (9–12岁)**: [核心观点] + [正向证据x2] + [反向/限制条件x1]。

## 5. 激励体系：行为章与地图
### 行为印章 (奖励学习行为而非结果)
- **证据章**: 成功引用原文并合理解释。
- **好奇章**: 提出了一个能引发讨论的好问题。
- **表达章**: 能用自己的话复述核心逻辑。
- **成长章**: 记录了观点的转变。
- **勇气章**: 面对难点多次尝试。

### 单元地图
- **主线**: 3-5 个节点（小节印章位），集齐解锁单元大勋章。
- **支线彩蛋**: 隐藏的“冷知识”或“小挑战”，完成后获得特殊装饰贴纸（如手绘胶带、金粉印章）。

## 6. AI 伴读精灵“木木”的角色
- **身份**: 手账编辑 + 盖章官 + 探险伙伴。
- **对话策略**:
  - **苏格拉底式提问**: “你怎么看？”、“证据在哪？”、“怎么写进手账？”
  - **最小线索提示**: 仅提供定位引导（如“找带‘但是’的句子”），不给直接答案。
  - **错误容忍**: 允许预测错误，将修正过程视为“成长”并给予奖励。

## 7. UI/UX 视觉风格
- **风格**: “治愈系成长手账”。
- **元素**: 拍立得照片、便利贴、手绘胶带、软糯的印章动效、纤维质感的厚纸背景。
- **核心组件**:
  - **左侧**: 带阴影和纸张感的 PDF 阅读区。
  - **右侧**: 拟物化的“手账编辑区”，支持拖拽证据贴纸。
